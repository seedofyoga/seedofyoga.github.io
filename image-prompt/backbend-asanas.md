# Image Prompts — Backbend Asanas

Illustration prompts for each pose in `content/blog/backbend-asanas.md`.

## Shared style

Every prompt below is built on this style. Keep it identical across all images
so the set stays visually consistent (matches `front-sitting.png`):

> Minimalist black-and-white line illustration, single female figure on a plain
> white background, clean thin black outlines, subtle light shading, hair in a
> neat top bun, simple athletic wear (sports bra and fitted shorts), floor
> indicated by a single thin horizontal line, calm and clean, no text, no color,
> centered composition.

Each prompt is ready to paste as-is.
